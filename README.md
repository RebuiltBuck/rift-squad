# Rift Squad

An offline pixel-art squad-tactics game for your phone.

Pick 3 heroes from a mash-up cast (knights, robots, ninjas, aliens, vampires, a dino mech...), set them up on a 5×5 half of the board, and watch them auto-battle the AI in best-of-5 matches (Captains, world synergies, Rift Events). Climb 15 arenas over the long haul: timed chests that unlock in real time, a 20,000-trophy road, monthly seasons with a reward track, and daily/weekly quests.

**Play:** open the GitHub Pages link on your phone, then *Share → Add to Home Screen*. After the first load it works with no connection.

Progress is stored on the device. Use **Settings → Backup** to copy a backup code now and then.
